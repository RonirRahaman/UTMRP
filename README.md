# 🛡️ UTMRP - Unauthorized Threat Monitor & Reporting Pipeline

UTMRP is a lightweight Linux-based security monitoring tool that detects unauthorized activities like failed SSH logins, sudo auth failures, and banned IPs from Fail2Ban — and generates human-readable reports. It is built using Bash and Python, ideal for security learners, sysadmins, and hobbyists.

---

## 🔧 Features

- 🔍 Detects:
  - Failed SSH login attempts
  - Sudo authentication failures
  - Banned IPs from Fail2Ban
- 📝 Generates timestamped security reports
- 💡 Simple CLI-based workflow (Bash + Python)
- 🐳 Docker-friendly
- ✅ No third-party services required (optional integrations possible)
